# VisionTrackAI scanner APK

Public download host for the Android scanner build used in the pilot.

- `visiontrack-scanner.apk` — current build
- sha256 is recorded in each commit message, so two builds that claim the
  same version are still tellable apart.

Direct link:

    https://raw.githubusercontent.com/visionquikcalude/apk/main/visiontrack-scanner.apk

Note that raw.githubusercontent.com serves with `Cache-Control: max-age=300`
and sits behind Fastly, so a freshly pushed build can take a few minutes to
appear at that URL. Link a commit-pinned URL instead when you need the
bytes to be exact:

    https://raw.githubusercontent.com/visionquikcalude/apk/<commit-sha>/visiontrack-scanner.apk
